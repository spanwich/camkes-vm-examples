WHY NETCAT DOESN'T WORK:
───────────────────────────────────────────────────────────────

The echo server operates at Layer 2 (raw Ethernet frames).
netcat operates at Layer 4 (TCP), which requires:
  - Layer 3: IP stack
  - Layer 2: Ethernet → IP mapping

QEMU's user networking (-netdev user) works at Layer 3 and doesn't
expose raw Ethernet frames to the guest.

To use netcat, you'd need to implement a full TCP/IP stack in the
guest (that's Tier 3!).
