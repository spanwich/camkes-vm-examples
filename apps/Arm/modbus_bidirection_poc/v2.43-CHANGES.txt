EXPECTED OUTPUT
===============

Minimal startup messages:
- Component initialization
- Version strings (v2.43-breadcrumb-only)
- Mode indicators

During operation:
- B<id> markers only (e.g., B2000, B2005, B3009)
- NO verbose debug output
- NO packet details
- NO metadata logging

TESTING STRATEGY
================

1. Build with v2.43 configuration
2. Test on SERVER CONSOLE (not SSH)
3. Watch for breadcrumb sequence before crash
4. Example expected output:
   
   B2000
   B2001
   B2003
   B2005
   B2007
   [CRASH] ← Crash occurred after B2007

5. Crash indicates problem between:
   - B2007: "Creating new TCP PCB"
   - B2009: "PCB created successfully"

REVERTING TO VERBOSE MODE
==========================

To restore full debug output for stable operation:

1. common.h: Set BREADCRUMB_TRACE = 0
2. Net0: Set DEBUG_LEVEL_NORMAL = 1, DEBUG_LEVEL_SILENT = 0
3. Net1: Set DEBUG_LEVEL_NORMAL = 1, DEBUG_LEVEL_SILENT = 0
4. ICS_Inbound: Set DEBUG_SILENT = 0
5. ICS_Outbound: Set DEBUG_SILENT = 0
