========================================
QUICK START - Remote Server (ens224/ens256)
========================================

Your server interface names: ens224, ens256

STEP 1: Extract Package
------------------------
tar xzf modbus_gateway_deploy.tar.gz
cd modbus_gateway_deploy

STEP 2: Configure Network
--------------------------
ETH0_NAME=ens224 ETH1_NAME=ens256 sudo -E ./setup-vlan-networking.sh

⚡ NEW: Scripts auto-detect interface names! If your interfaces already have
the correct IPs (192.168.95.2 and 192.168.90.1), you can just run:
  sudo ./setup-vlan-networking.sh

What this does:
  ✓ Configures ens224 → 192.168.95.2/24 (impersonates PLC)
  ✓ Configures ens256 → 192.168.90.1/24 (impersonates router)
  ✓ Creates tap0 → 10.2.0.1/24 (QEMU Net0)
  ✓ Creates tap1 → 10.3.0.1/24 (QEMU Net1)
  ✓ Enables IP forwarding
  ✓ Configures iptables NAT rules (auto-detects interface names)

STEP 3: Start Gateway
----------------------
./run-remote.sh

Expected output:
  ========================================
  VLAN-based ICS Security Gateway
  ========================================

  Network Configuration:

  Physical NICs:
    ens224: 192.168.95.2/24 (impersonates PLC)
    ens256: 192.168.90.1/24 (impersonates router)

  TAP Interfaces (Private Networks):
    tap0: 10.2.0.1/24 (QEMU Net0 gateway)
    tap1: 10.3.0.1/24 (QEMU Net1 gateway)

  Starting QEMU...

STEP 4: Verify (in another terminal)
-------------------------------------
# Test QEMU guest connectivity
ping 10.2.0.2  # Should reach QEMU Net0
ping 10.3.0.2  # Should reach QEMU Net1

# Check configuration
ip addr show ens224  # Should have 192.168.95.2
ip addr show ens256  # Should have 192.168.90.1

# Check NAT rules
sudo iptables -t nat -L -n -v | grep "10.2.0.2\|10.3.0.2"

TROUBLESHOOTING
---------------
Error: "eth0 not found"
  → You forgot to set ETH0_NAME/ETH1_NAME
  → Use: ETH0_NAME=ens224 ETH1_NAME=ens256 sudo -E ./setup-vlan-networking.sh

Error: "TAP interfaces not found"
  → Run setup first: ETH0_NAME=ens224 ETH1_NAME=ens256 sudo -E ./setup-vlan-networking.sh

Error: "iptables NAT rules not configured"
  → Rules included in setup-vlan-networking.sh
  → Or run separately: ETH0_NAME=ens224 ETH1_NAME=ens256 sudo -E ./setup-iptables.sh
  → Or if IPs already configured: sudo ./setup-iptables.sh (auto-detects)

QEMU starts but no connectivity:
  → Check: ip addr show tap0 tap1
  → Check: sudo iptables -t nat -L -n -v
  → Check: cat /proc/sys/net/ipv4/ip_forward (should be 1)

STOPPING QEMU
-------------
Inside QEMU console: Press Ctrl-A then X
From another terminal: pkill -9 qemu-system-arm

AFTER REBOOT
------------
Configuration is NOT persistent!
Re-run: ETH0_NAME=ens224 ETH1_NAME=ens256 sudo -E ./setup-vlan-networking.sh

To make persistent, see: REMOTE_SERVER_SETUP.md

NETWORK TOPOLOGY
----------------
[Router 192.168.95.1] ←→ [ens224: 192.168.95.2] (impersonates PLC)
                               ↓ (iptables DNAT)
                          [tap0: 10.2.0.1]
                               ↓
                          [QEMU Net0: 10.2.0.2] (security gateway)
                               ↓
                          [QEMU Net1: 10.3.0.2]
                               ↓
                          [tap1: 10.3.0.1]
                               ↓ (iptables SNAT)
                          [ens256: 192.168.90.1] (impersonates router)
                               ↓
                          [Real PLC: 192.168.95.2]

IMPORTANT: Real PLC must be on secure VLAN (connected via ens256)!
