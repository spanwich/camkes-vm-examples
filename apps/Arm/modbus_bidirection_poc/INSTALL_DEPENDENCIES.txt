========================================
INSTALL DEPENDENCIES - Remote Server
========================================

REQUIRED SOFTWARE
-----------------
1. QEMU (qemu-system-arm)
2. iptables
3. iproute2 (usually pre-installed)

INSTALLATION COMMANDS
---------------------

For Ubuntu/Debian:
------------------
sudo apt update
sudo apt install -y qemu-system-arm iptables iproute2

For RHEL/CentOS/Rocky:
----------------------
sudo yum install -y qemu-system-arm iptables iproute2

For Fedora:
-----------
sudo dnf install -y qemu-system-arm iptables iproute2

VERIFY INSTALLATION
-------------------
# Check QEMU
qemu-system-arm --version
# Expected: QEMU emulator version 6.x or higher

# Check iptables
iptables --version
# Expected: iptables v1.8.x

# Check ip command
ip -V
# Expected: ip utility, iproute2-x.x.x

MINIMUM VERSIONS
----------------
QEMU:      6.0 or higher
iptables:  1.8.0 or higher
iproute2:  5.0 or higher

TROUBLESHOOTING
---------------

"qemu-system-arm: command not found"
  → Install QEMU: sudo apt install qemu-system-arm

"iptables: command not found"
  → Install iptables: sudo apt install iptables

"Permission denied" when running scripts
  → Make scripts executable: chmod +x *.sh
  → Run with sudo: sudo ./setup-vlan-networking.sh

"Package not found"
  → Update package list first: sudo apt update
  → Try alternative package names:
      qemu-system (generic package)
      qemu-kvm (includes qemu-system-arm on some distros)

OPTIONAL: iptables-persistent
-----------------------------
To save iptables rules across reboots:

sudo apt install iptables-persistent

During installation, it will ask to save current rules.
After setup, save with:

sudo netfilter-persistent save

DISK SPACE REQUIREMENTS
-----------------------
Minimum: 500 MB for QEMU and dependencies
Recommended: 1 GB free space

KERNEL REQUIREMENTS
-------------------
Must support:
- TUN/TAP devices (CONFIG_TUN=y or m)
- IP forwarding
- Netfilter/iptables (CONFIG_NETFILTER=y)

Check kernel support:
  lsmod | grep tun        # Should show 'tun' module
  ls /dev/net/tun         # Should exist

If missing TUN/TAP:
  sudo modprobe tun
  sudo mknod /dev/net/tun c 10 200

SECURITY CONSIDERATIONS
-----------------------
The gateway requires:
- Root access (for network configuration)
- TAP interface creation
- iptables rule modification
- IP forwarding

Ensure your security policies allow these operations.

AFTER INSTALLATION
------------------
Proceed with deployment:
  1. Extract package: tar xzf modbus_gateway_deploy.tar.gz
  2. Read quick start: cat QUICK_START_ens224_ens256.txt
  3. Configure network: ETH0_NAME=ens224 ETH1_NAME=ens256 sudo -E ./setup-vlan-networking.sh
  4. Start gateway: ./run-remote.sh
